# 🎧 Over-Ear Headphone ANC & Audio Matrix Dashboard

An interactive Streamlit application that evaluates over-ear headphones across dynamic performance dimensions: **Active Noise Cancellation (dB)**, **Sound Quality**, **Bass Intensity**, and **Durability** mapped against **Price (£ GBP)**.

## 🚀 Live Demo & Deployment

### Run Locally
```bash
# 1. Clone repository
git clone [https://github.com/](https://github.com/)<your-username>/headphone-anc-matrix.git
cd headphone-anc-matrix

# 2. Set up virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch Streamlit
streamlit run app.py
```

### Deploy to Streamlit Cloud (1-Click)
1. Push this repository to GitHub.
2. Sign in to [share.streamlit.io](https://share.streamlit.io).
3. Click **"New App"** -> Select your repo -> Branch `main` -> Main file path `app.py`.
4. Click **Deploy**.
